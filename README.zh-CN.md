# 线国猫 Linecat

[English](README.md) · 中文

一个给 Claude Code 桌面版 Code 标签页用的 mod（函数钩子插件）。一只像素猫住在输入框上方的一条横栏里，沿着一条线散步。这条线随着你的会话一点点展开，猫的头顶实时显示 Claude 正在做什么。标签页的其余部分换成复古游戏菜单的样子：纸张面板配实色标题栏，浅色和深色主题都适用。

- **消息**：你的消息和 Claude 的回复画成带标题栏（`INPUT` / `REPORT`）的直角面板。正文是一层暖色半透明底，文字和标题栏用主题自己的颜色，所以浅色主题下是纸色面板配深色标题栏，深色主题下是暗暖色面板配浅色标题栏，不需要任何设置。
- **输入框上方的横栏**，左右两块，比例 6:4：
  - **STANDBY**：线国，取自[《四维来客》](https://github.com/fivood/claudewant)的桌宠模式。一条随会话展开的纸线：读文件积成水，跑命令推起山，改代码长出树，出错划破成裂缝。一个像素角色（默认是猫）在线上闲逛，爬山、跳过裂缝，安静两分钟后蜷起来睡觉。
    - **纸张**是原作十种地貌之一，每个会话开始时随机抽一种（热重载不会换）：地球、二向箔、沙丘、索拉里斯、晶化、电路板、水墨、蓝图、切片、深空。每种有自己的配色、山和树的画法，以及一个专属的小动画：飘过的云、压平的余震、线下游过的沙虫、两个太阳、游走的光斑、沿走线跑的数据包、远山、图纸网格、漂动的细胞核、闪烁的星星和流星。`/lineland` 把同一条线随机换到另一张纸上，`/lineland 沙丘`（或 `/lineland dune`）换到指定的那张；回复进行中也能用。
    - **Claude Code 正在做什么**显示在角色头顶（带一圈细细的浅色描边，任何背景上都看得清），也显示在底部那行：

      | 状态 | 头顶 | 底部 |
      |---|---|---|
      | 刚发出消息 | `!` | `INPUT RECEIVED` |
      | 等待模型 | 信号格 | `CONNECTING` |
      | 思考中（背过身） | 三个点依次亮起 | `ANALYZING` |
      | 写回复 | 一行行打出的字 | `TRANSMITTING` |
      | 正在写工具调用 | 该工具的图标，闪烁 | `PREPARING: <工具>` |
      | 工具运行中 | 文档、放大镜、终端、铅笔、地球、分支（子代理）、清单、插头（MCP）、火花（技能）、齿轮 | `EXECUTE: <工具>` |
      | 等你批准权限 | 黄色 `?` | `AWAITING AUTHORIZATION: <工具>` |
      | 工具出错 / 被拒绝 | 红色 `!` / 红色 `×` | `ERROR` / `DENIED` |
      | 被打断 | `■` | `INTERRUPTED` |
      | 压缩上下文 | 沙漏 | `COMPRESSING MEMORY` |
      | 闲置两分钟 | z z z | `SLEEP MODE` |

      子代理自己的步骤和调用不会改变它，显示的是主线程那次 `Agent` 调用。
  - **RESOURCE MONITOR**：5 小时 / 7 天额度和上下文占用，用对齐的 `■□` 进度条显示，并注明重置时间（`RESET 20:00`；不是今天的话写成 `RESET 10/13 20:00`）。
- **语言**：旁白、地貌名和开场白、`/lineland` 的回复都有中文、日本語和 English 三种。**Language** 设置（在 `/config` 里，安装时也会问）可以指定一种，或者选 `auto`：Claude Code 有回复语言设置时跟着它，否则按你第一条消息的文字判断。状态词（`EXECUTE`、`ANALYZING` 等）特意保留英文，算是风格的一部分。
- **思考行**：`■ PROCESSING  12s  ·  340 tokens`。
- **工具调用行**：左侧一道竖条，工具名、操作对象、状态，以及纯文本输出的前几行。

角色是像素画，以一行行字母的可读形式保存（`hooks/sprite.ts`，一个字母代表一种颜色），mod 载入时转成 SVG 方块；这个文件由 `sheet2ts.py` 从 Aseprite 导出的精灵图生成。

## 安装

在终端版 `claude` 会话的输入框里：

```
/plugin install linecat --marketplace fivood/linecat
```

按 `y` 添加插件市场，再选安装范围（第一个是用户范围）。装在用户范围时，桌面 App 的 Code 标签页也会加载它，猫和地貌就画在那里；终端会话里有面板和额度条，但没有 SVG 那一栏。

如果想从克隆的仓库直接加载，在 `~/.claude/settings.json` 里指向这个文件夹：

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "C:\\path\\to\\linecat" } }
```

或者只在一次会话里用：`claude --plugin-dir /path/to/linecat`。

## 它读取和发送什么

它只负责画。它读取会话自己的用量数字（额度窗口和上下文占用）、工具调用运行时的名字和参数、输出流所处的阶段（思考、回复、工具参数）、权限对话框何时弹出、上下文压缩和每轮结束，并保存少量会话状态（这条线、选中的地貌、一个计时器）。它不向任何地方发送任何东西，不发网络请求，不读写文件，不运行进程。它在工具调用、权限检查、消息、输出流、压缩和每轮上的钩子都只做观察：每个事件都原样传下去，所以不会改动任何调用、消息或权限决定。只有绘制钩子会替换 App 画出来的东西，而且只影响屏幕显示；Claude 读到的对话记录不受影响。

**权限钩子。** 有一个钩子在 Claude Code 弹出权限对话框时运行（`PermissionRequest`）。它只在猫头顶放一个黄色 `?`，在底部写上 `AWAITING AUTHORIZATION`，然后把事件原样传下去。它从不读取、修改或回答这个决定：批准还是拒绝，完全由你自己决定。

**工具调用钩子。** `tool.call` 钩子能看到每一次工具调用，包括其他代码发起的调用，用来让线长出地形、让猫头顶显示对应的工具图标。它把每次调用原样传下去，只读取工具名，以及调用是否出错或被拒绝。

## 换角色

从 Aseprite 导出精灵图和 JSON（方形帧，最大约 32 像素），然后：

```
python sheet2ts.py sheet.png sheet.json hooks/sprite.ts "Artwork (c) you"
```

用到的帧标签：

| 标签 | 什么时候 | |
|---|---|---|
| `idle_front` | 站着 | 必需；缺少的标签都会退回到它 |
| `idle_back` | Claude 在思考 | |
| `walk_front` | 走路 | |
| `sleep_front` | 安静两分钟后 | |

`_front` 姿态请画成朝右：角色往左走时会水平镜像，停下后保持最后走的方向。`_back` 姿态不会镜像。

需要 Pillow。

## 限制

桌面 App 自己的背景、横栏外那圈灰色边框、每轮的「Ran a command…」折叠行和系统提示都无法通过 mod 修改，保持 App 原样。
